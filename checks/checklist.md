# Human Review Checklist

Run through this before trusting a newly built rubric on anything with real stakes.

- [ ] Every scoring area names something specific to check, not a vague feeling
- [ ] The automatic-failure list came from an actual bad example, not an invented worst case
- [ ] The scale (1 to 5) has a one-line meaning for each point, not just numbers
- [ ] The rubric has ten areas or fewer
- [ ] At least one real output has been scored against it, not just the example it was built from
- [ ] If no bad example existed yet, the rubric was not built anyway on a guessed one
