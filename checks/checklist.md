# Human Review Checklist

Go through this before you trust a new rubric with anything important.

- [ ] Every scoring area names something specific to check, not a vague feeling
- [ ] The automatic failures came from a real bad example, not an imagined worst case
- [ ] Each point on the scale (1 to 5) has a one-line meaning, not just a number
- [ ] The rubric has ten areas or fewer
- [ ] You've scored at least one real output with it, not just the example it was built from
- [ ] If there was no bad example yet, nobody built the rubric anyway on a guessed one
