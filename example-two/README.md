# Worked Example Two: A Harder Case

The first [example](../example/) tests whether a finished rubric catches a real failure. This one tests something harder. Does the skill know when it hasn't got enough to build an honest rubric, or does it invent a bad example so it can produce something that looks complete?

- [inputs.md](inputs.md): two good examples, but no real bad example, only "I'd just know it if I saw it"
- [output.md](output.md): the response, which stops rather than guesses
- [review.md](review.md): whether stopping was right, and whether it still offered something useful
