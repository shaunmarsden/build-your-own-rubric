# Worked Example

Fictional scenario: Thornbury Outfitters, an entirely made-up online retailer, building a rubric for AI-drafted customer support replies.

- [inputs.md](inputs.md): the task, good examples, a bad example, and the cost of a missed failure, gathered as [SKILL.md](../SKILL.md) asks for
- [rubric.md](rubric.md): the finished rubric built from those inputs
- [scored-sample.md](scored-sample.md): the rubric applied to a new reply, deliberately built with a subtler version of the original failure to check the rubric actually generalises rather than only catching the exact case it was built from
- [review.md](review.md): whether it actually worked
